# Nom du projet

## Nom retenu : **DataBastion**
Plateforme DLP open-source qui protège les données au plus près des bases et annuaires, via des agents outbound.

Un bastion est une fortification avancée. L'image correspond au positionnement : défendre la donnée *là où elle réside*. Le logo (bouclier + base de données) est dans [assets/logo.jpg](assets/logo.jpg).

# Project name

## Chosen name: **DataBastion**
Open-source DLP platform that protects data as close as possible to databases and directories, through outbound agents.

A bastion is an advanced fortification. The image matches the positioning: defending data *where it resides*. The logo (shield + database) is in [assets/logo.jpg](assets/logo.jpg).

## Candidates considered (history)

# Politique de marque

Le code de DataBastion Community Edition est sous licence Apache 2.0. Comme le prévoit sa section 6, cette licence **n'accorde aucun droit** sur le nom « DataBastion » ni sur le logo.

## Autorisé sans demande
- Dire que votre produit ou service « utilise DataBastion », « est compatible avec DataBastion » ou « est basé sur DataBastion »
- Utiliser le nom dans des articles, tutoriels, conférences ou supports de formation
- Redistribuer les versions officielles non modifiées sous leur nom

## Soumis à autorisation écrite
- Distribuer une version **modifiée** sous le nom « DataBastion » (un fork doit changer de nom)
- Proposer un service hébergé nommé « DataBastion » ou dont le nom peut être confondu avec lui
- Utiliser le logo dans un produit commercial

Pour toute demande, ouvrir une discussion sur le dépôt.
